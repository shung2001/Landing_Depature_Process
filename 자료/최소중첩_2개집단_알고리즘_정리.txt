버티포트별 POLYGON의 최소 중첩 2개 집단 배치
관련 개념·알고리즘·수학적 모델 정리
============================================================

작성일: 2026-09-25


1. 문제 정의
------------------------------------------------------------

자료/결과물/Polygon/12.5 아래의 ID 1~36 폴더에는 각 버티포트의
방위각별 polygon 후보가 들어 있다.

목표는 다음과 같이 정의할 수 있다.

1) 각 ID에서 두 개의 방위각 polygon을 선택한다.
2) 선택한 두 polygon은 원형 방위각 차이가 지정된 기준 이상이어야 한다.
   예: 최소 방위각 차이 70도.
3) 선택한 polygon 중 하나는 제1집단에, 다른 하나는 제2집단에 배치한다.
4) 제1집단 내부에서 발생하는 서로 다른 ID polygon의 중첩을 최소화한다.
5) 제2집단 내부에서 발생하는 서로 다른 ID polygon의 중첩도 최소화한다.
6) 가능하면 특정 ID에 중첩이 집중되지 않도록 최대 개별 중첩개수도
   함께 낮춘다.

최종 결과의 예시는 다음과 같다.

id | 제1집단 방위각 | 제1집단 중첩개수 | 제2집단 방위각 | 제2집단 중첩개수
---+-----------------+-------------------+-----------------+------------------
1  | 222             | 3                 | 292             | 2
2  | 271             | 4                 | 341             | 1
3  | 137             | 2                 | 42              | 3
...| ...             | ...               | ...             | ...
36 | 297             | 1                 | 229             | 2

여기서 집단별 중첩개수는 모든 원본 후보에 대한 중첩개수가 아니라,
최종적으로 같은 집단에 선택된 다른 35개 ID의 polygon 중 몇 개와
면적으로 겹치는지를 다시 계산한 값이어야 한다.


2. 개별 최소 선택과 전역 최소 배치의 차이
------------------------------------------------------------

각 ID에서 기존 중첩개수가 가장 작은 polygon 두 개를 독립적으로 고르는
방법은 전체 집단의 중첩을 최소화하지 못할 수 있다.

예를 들어 ID 1의 개별 최저 후보와 ID 2의 개별 최저 후보가 서로 겹친다면,
각각의 독립적인 점수는 좋아도 최종 집단에서는 중첩이 발생한다.
반대로 각 ID에서 두 번째나 세 번째로 좋은 후보를 선택하면 최종 집단
전체의 중첩이 더 작아질 수 있다.

따라서 다음 방식은 전역 최적해를 보장하지 않는다.

    각 ID별 중첩개수 최소 polygon 선택
    → 선택된 polygon을 두 집단에 배치

대신 다음 요소를 동시에 판단해야 한다.

    ID별 방위각 후보 선택
    + 제1집단/제2집단 배치
    + 선택된 polygon 사이의 중첩 계산
    → 집단 내부의 전체 중첩 최소화


3. Polygon intersection graph / Conflict graph
------------------------------------------------------------

GIS polygon을 그래프로 변환하면 관련 알고리즘을 적용하기 쉽다.

그래프 노드:
    하나의 (ID, 방위각) polygon

그래프 간선:
    서로 다른 ID의 두 polygon이 양의 면적으로 겹치면 두 노드를 연결

간선 가중치 예시:
    - 단순 중첩 여부: 1
    - 중첩 면적: 교차 면적(m²)
    - 중요도를 반영한 위험 점수: 사용자 정의 가중치

예:

    노드 A = (id=1, 방위각=222도)
    노드 B = (id=2, 방위각=271도)
    노드 C = (id=3, 방위각=137도)

    A와 B가 면적으로 겹침 → A-B 간선 생성
    A와 C가 겹치지 않음   → 간선 없음
    B와 C가 면적으로 겹침 → B-C 간선 생성

이러한 그래프를 geometric intersection graph 또는 용도에 따라
conflict graph라고 부를 수 있다.

처리 흐름:

    Polygon 공간자료
           ↓
    공간 인덱스로 면 중첩 판정
           ↓
    Conflict graph 생성
           ↓
    그래프/조합최적화 알고리즘 적용

검색어:

    polygon intersection graph
    geometric intersection graph optimization
    spatial conflict graph
    polygon conflict graph assignment


4. Max-Cut / Max-Bisection
------------------------------------------------------------

각 ID에서 사용할 polygon이 이미 하나씩 정해져 있고, 선택된 polygon들을
두 집단으로 나누는 문제라면 Max-Cut이 가장 직접적인 관련 개념이다.

중첩 그래프에서:

    - 같은 집단에 있는 두 polygon이 겹치면 집단 내부 중첩 발생
    - 서로 다른 집단으로 보내면 해당 중첩은 집단 내부에서 제거됨
    - 따라서 중첩 간선을 가능한 한 많이 두 집단 사이로 보내야 함

전체 중첩 간선 집합을 E, 집단 사이를 가로지르는 간선 집합을 C라고 하면:

    집단 내부 중첩 수 = |E| - |C|

따라서:

    집단 내부 중첩 최소화
    ⇔ 집단 사이의 중첩 간선 최대화

이것이 Max-Cut 문제다.

두 집단의 크기를 정확히 같게 해야 한다면 Max-Bisection 문제가 된다.
예를 들어 36개 ID 자체를 두 집단으로 나누면서 각 집단에 18개 ID를
배치해야 하는 경우가 이에 해당한다.

중요한 제한:

Max-Cut은 각 ID의 polygon이 이미 정해진 경우에는 정확히 맞지만,
ID별 방위각 후보 선택까지 동시에 해야 하는 전체 문제에는 Max-Cut만으로
충분하지 않다.

대표 참고문헌:

Michel X. Goemans, David P. Williamson,
"Improved Approximation Algorithms for Maximum Cut and Satisfiability
Problems Using Semidefinite Programming," Journal of the ACM, 1995.

PDF:
https://math.mit.edu/~goemans/PAPERS/maxcut-jacm.pdf

DOI:
https://doi.org/10.1145/227683.227684

이 논문은 Max-Cut에 대해 기대값 기준 약 0.87856의 근사비를 보장하는
반정의계획법 기반 알고리즘을 제시한다.


5. Independent transversal
------------------------------------------------------------

각 ID를 하나의 후보 블록으로 생각할 수 있다.

    ID 1 후보 블록:
    (1, 0도), (1, 1도), ..., (1, 359도)

    ID 2 후보 블록:
    (2, 0도), (2, 1도), ..., (2, 359도)

    ...

    ID 36 후보 블록:
    (36, 0도), ..., (36, 359도)

각 블록에서 정확히 하나의 노드를 선택하고, 선택된 노드 사이에 중첩
간선이 전혀 없어야 한다면 independent transversal 문제에 해당한다.

현재 문제로 표현하면:

    각 ID에서 polygon 하나씩 선택
    + 선택된 polygon 사이의 중첩이 모두 0

실제 데이터에서 중첩 0인 완전한 해가 존재하지 않을 수 있다. 이때는
독립 조건을 완화하여 다음 문제로 바꿀 수 있다.

    각 ID에서 하나씩 선택하되,
    선택된 polygon 사이의 중첩 간선 수를 최소화

이는 soft independent transversal 또는 penalized independent transversal
형태로 생각할 수 있다. 이 명칭이 하나의 완전히 표준화된 문제명은
아니지만 수학적 구조는 independent transversal의 완화형이다.

참고자료:

Alessandra Graf, Penny Haxell,
"Finding Independent Transversals Efficiently."

https://arxiv.org/abs/1811.02687


6. Selective graph coloring
------------------------------------------------------------

Selective graph coloring의 기본 구조:

    - 그래프 노드가 여러 클러스터로 나뉨
    - 각 클러스터에서 정확히 하나의 노드를 선택
    - 선택된 노드로 구성된 부분 그래프를 가능한 적은 색으로 색칠

현재 문제와의 대응:

    클러스터 = ID
    노드       = 해당 ID의 방위각 polygon
    간선       = polygon 중첩
    색         = 운용 집단

색을 두 개만 허용하면 제1집단과 제2집단에 대응한다.

Selective graph coloring은 보통 필요한 색의 수를 최소화한다. 현재 문제는
색의 수를 2개로 고정하고, 완전한 2색칠이 불가능할 때 같은 색 내부에 남는
간선 수를 최소화한다는 차이가 있다. 따라서 정확히 동일한 문제는 아니지만
매우 가까운 연구 분야다.

관련 검색어:

    selective graph coloring
    clustered graph coloring
    partitioned graph coloring
    soft selective coloring
    minimum conflict coloring
    minimum uncut problem

주의:

그래프 이론의 conflict-free coloring은 각 노드의 이웃에서 유일한 색이
존재하도록 하는 별도의 개념이다. 현재 문제에는 일반적인 conflict graph
coloring 또는 minimum-conflict coloring이라는 표현이 더 적절하다.

참고자료:

Oylum Seker, Tinaz Ekim, Z. Caner Taskin,
"An Exact Cutting Plane Algorithm to Solve the Selective Graph Coloring
Problem in Perfect Graphs."

https://arxiv.org/abs/1811.12094


7. 현재 문제에 적합한 이진 이차 최적화 모델
------------------------------------------------------------

각 ID i에 대해 최소 방위각 이격 조건을 만족하는 후보 쌍 집합 P_i를 만든다.

    P_i = {(a,b): a와 b는 ID i의 후보이고 원형 각도 차이 ≥ 기준각}

예를 들어 최소 방위각 차이가 70도인 경우:

    (222도, 292도)
    (223도, 293도)
    (224도, 294도)
    ...

원형 방위각 차이는 다음과 같이 계산해야 한다.

    circular_difference(a,b) = min(|a-b|, 360-|a-b|)

예:

    10도와 80도   → 차이 70도
    350도와 60도  → 원형 차이 70도
    350도와 20도  → 원형 차이 30도

각 후보 쌍에서:

    첫 번째 방위각 → 제1집단
    두 번째 방위각 → 제2집단

으로 정의할 수 있다. 반대 배치도 고려하려면 순서를 뒤집은 후보 쌍을
별도로 생성한다.

ID i의 후보 쌍 p와 ID j의 후보 쌍 q 사이 비용을 다음처럼 정의한다.

    c(i,p,j,q)
      = I(제1집단 polygon끼리 중첩)
      + I(제2집단 polygon끼리 중첩)

I는 중첩되면 1, 아니면 0인 지시함수다.

예:

    ID 1 후보 쌍:
    제1집단 = 222도
    제2집단 = 292도

    ID 2 후보 쌍:
    제1집단 = 271도
    제2집단 = 341도

    비용 = overlap((1,222도), (2,271도))
         + overlap((1,292도), (2,341도))

이진 선택변수:

    x(i,p) = ID i에서 후보 쌍 p를 선택하면 1, 아니면 0

각 ID에서 후보 쌍 하나만 선택하는 제약:

    모든 i에 대해 sum(x(i,p), p ∈ P_i) = 1

목적함수:

    minimize
    sum(c(i,p,j,q) * x(i,p) * x(j,q))
    for all i < j, p ∈ P_i, q ∈ P_j

관련 문제명 및 검색어:

    multiple-choice binary quadratic optimization
    multiple-choice quadratic programming
    partitioned binary quadratic optimization
    quadratic assignment with grouped alternatives
    QUBO with one-hot constraints
    pairwise cost assignment problem

한글 표현:

    그룹별 하나 선택 제약을 가진 이진 이차 최적화 문제

현재 문제를 비교적 정확하게 표현하면 다음과 같다.

    Polygon intersection graph 위에서 ID별 방위각 쌍 하나를 선택하고,
    두 집단 내부의 중첩 비용을 최소화하는 multiple-choice binary
    quadratic optimization 문제.


8. CP-SAT 또는 MILP 선형화
------------------------------------------------------------

목적함수의 x(i,p) * x(j,q)는 이차항이다. 이차항을 직접 처리할 수 있는
솔버를 사용하거나, 보조변수 y를 사용해 선형화할 수 있다.

    y(i,p,j,q) = x(i,p) * x(j,q)

선형화 제약:

    y(i,p,j,q) ≤ x(i,p)
    y(i,p,j,q) ≤ x(j,q)
    y(i,p,j,q) ≥ x(i,p) + x(j,q) - 1

그러면 목적함수는 다음과 같은 선형식이 된다.

    minimize sum(c(i,p,j,q) * y(i,p,j,q))

이 문제는 Google OR-Tools CP-SAT이나 MILP 솔버로 풀 수 있다.
현재 변수의 대부분은 선택 여부를 나타내는 Boolean이므로 CP-SAT 구조와
잘 맞는 편이다.

OR-Tools 공식 문서:

Integer optimization:
https://developers.google.com/optimization/mip

CP-SAT:
https://developers.google.com/optimization/cp/cp_solver

Integer arithmetic 및 곱 제약:
https://github.com/google/or-tools/blob/stable/ortools/sat/docs/integer_arithmetic.md

변수 수를 줄이기 위한 중요한 방법:

    - 중첩하지 않는 후보 쌍은 비용이 0이므로 y 변수를 만들지 않는다.
    - 실제 중첩 관계가 있는 후보 쌍에 대해서만 보조변수를 생성한다.
    - ID별 후보 수를 방위각 다양성을 유지하면서 사전에 축소한다.

CP-SAT 결과 상태 해석:

    OPTIMAL    최적해임이 증명됨
    FEASIBLE   실행 시간 안에 찾은 유효한 최선해이나 최적 증명은 안 됨
    INFEASIBLE 주어진 강제조건을 만족하는 해가 없음
    UNKNOWN    제한 시간 안에 해 존재 또는 최적성을 판단하지 못함


9. 휴리스틱 및 메타휴리스틱
------------------------------------------------------------

9.1 탐욕 알고리즘

ID를 하나씩 처리하면서 현재 두 집단에 추가되는 중첩 수가 가장 작은
방위각 쌍과 배치를 선택한다.

각 후보 쌍 (a,b)에 대해 두 배치를 비교한다.

    배치 A:
    a → 제1집단
    b → 제2집단

    배치 B:
    a → 제2집단
    b → 제1집단

추가 비용:

    cost_A = a가 현재 제1집단과 만드는 중첩
           + b가 현재 제2집단과 만드는 중첩

    cost_B = a가 현재 제2집단과 만드는 중첩
           + b가 현재 제1집단과 만드는 중첩

작은 비용의 배치를 선택한다.

단점:

초반 ID 선택이 이후 선택을 제한하기 때문에 전역 최적해를 보장하지 않는다.
ID 처리 순서를 여러 번 바꾸어 실행하면 결과를 개선할 수 있다.


9.2 GRASP

GRASP는 다음 과정을 반복한다.

    1) 탐욕적으로 좋은 후보를 계산
    2) 최상위 후보들 중 하나를 무작위로 선택
    3) 완성된 해에 지역 탐색 적용
    4) 여러 번 반복
    5) 가장 좋은 결과 보존

현재 문제 적용 예:

    1) 아직 배치하지 않은 ID 선택
    2) 가능한 방위각 쌍별 추가 중첩 비용 계산
    3) 비용이 낮은 상위 후보 목록 작성
    4) 목록에서 하나를 무작위 선택
    5) 36개 ID를 모두 배치
    6) ID 하나의 방위각 쌍을 변경하는 지역 탐색
    7) 전체 과정을 여러 번 재시작

현재 규모에서 구현 난이도와 결과 품질의 균형이 좋은 방법이다.

참고문헌:

Thomas A. Feo, Mauricio G. C. Resende,
"Greedy Randomized Adaptive Search Procedures,"
Journal of Global Optimization, 1995.

https://mauricio.resende.info/doc/gtut.pdf


9.3 Tabu search

지역 탐색이 같은 해 주변을 반복하는 것을 막기 위해 최근 변경을 일정
기간 금지하는 방법이다.

예:

    ID 5의 방위각 쌍을
    (220도, 290도) → (225도, 295도)
    로 바꾸었다면, 일정 반복 동안 바로 원래 쌍으로 되돌아가는 이동을 금지

참고문헌:

Fred Glover,
"Tabu Search—Part I,"
ORSA Journal on Computing, 1989.

https://pubsonline.informs.org/doi/10.1287/ijoc.1.3.190


9.4 Simulated annealing

비용이 조금 나빠지는 이동도 온도에 따른 확률로 허용하여 지역 최솟값에서
빠져나오는 방법이다.

가능한 이동 연산:

    - 한 ID의 제1집단 방위각 변경
    - 한 ID의 제2집단 방위각 변경
    - 한 ID의 두 집단 방위각을 서로 교환
    - 한 ID의 방위각 쌍 전체 변경
    - 두 ID의 후보 쌍을 동시에 변경


9.5 Kernighan–Lin 계열 swap 탐색

Kernighan–Lin은 노드 교환을 통해 그래프 분할 비용을 개선하는 고전적인
휴리스틱이다.

주의:

원래 Kernighan–Lin은 두 집단 사이의 cut 비용을 최소화하는 문제를
대상으로 한다. 현재처럼 집단 내부 중첩을 최소화하고 집단 사이의 cut을
최대화하려면 목적함수의 부호와 이동 이득 계산을 반대로 구성해야 한다.
따라서 원 알고리즘을 그대로 사용하기보다는 swap 기반 지역 탐색 구조를
참고하는 것이 적절하다.

참고문헌:

B. W. Kernighan, S. Lin,
"An Efficient Heuristic Procedure for Partitioning Graphs,"
Bell System Technical Journal, 1970.

https://onlinelibrary.wiley.com/doi/10.1002/j.1538-7305.1970.tb01770.x


10. 목적함수 설계
------------------------------------------------------------

10.1 전체 중첩 쌍 수 최소화

    minimize
    제1집단 내부 중첩 쌍 수 + 제2집단 내부 중첩 쌍 수

가장 단순하고 계산하기 쉬운 목적함수다.

polygon별 중첩개수 합과 중첩 쌍 수의 관계:

    polygon별 중첩개수 합 = 2 × 중첩 polygon 쌍 수

각 중첩 쌍이 양쪽 polygon에서 한 번씩 집계되기 때문이다.


10.2 최대 개별 중첩개수 최소화(Minimax)

    minimize max(모든 선택 polygon의 집단 내부 중첩개수)

특정 ID 하나에 중첩이 집중되는 것을 방지한다.

예:

    해 A: 전체 중첩 쌍 30, 최대 개별 중첩 12
    해 B: 전체 중첩 쌍 32, 최대 개별 중첩 5

총중첩만 보면 A가 좋지만, 안전성의 균형 측면에서는 B가 더 적절할 수 있다.


10.3 사전식(Lexicographic) 최적화

권장 방식:

    1차 목표: 최대 개별 중첩개수 최소화
    2차 목표: 최대값이 같은 해 중 전체 중첩개수 최소화

CP-SAT을 두 번 실행하는 방법:

    1차 실행:
    최대 개별 중첩개수의 최솟값 Z* 계산

    2차 실행:
    최대 개별 중첩개수 ≤ Z* 제약 추가
    전체 중첩 쌍 수 최소화

이 방식은 임의의 가중치를 정하는 것보다 목적의 우선순위가 명확하다.


10.4 중첩 면적 반영

단순 중첩 여부 외에 중첩 면적을 목적함수에 포함할 수 있다.

    비용 = 중첩 쌍 수 + lambda × 총 중첩 면적

주의:

EPSG:4326 상태에서 geometry.area를 계산하면 단위가 제곱미터가 아니라
제곱도이므로 실제 면적 의미가 없다. 면적을 목적함수에 사용할 때는
EPSG:5186 등 적절한 미터 기반 투영좌표계로 변환한 뒤 계산해야 한다.


11. 후보 수 축소
------------------------------------------------------------

각 ID에 55~360개의 후보가 있다면 모든 후보 쌍과 모든 ID 조합을 직접
최적화하는 것은 매우 크다.

ID 하나에 360개의 후보가 있을 때 두 polygon 조합 수:

    C(360,2) = 64,620

이 조합을 36개 ID에 대해 결합한 완전탐색은 사실상 불가능하다.

권장 축소 방법:

1) 방위각 구간별 우수 후보 보존

    0~29도 구간에서 상위 1~3개
    30~59도 구간에서 상위 1~3개
    ...
    330~359도 구간에서 상위 1~3개

2) 방위각 비최대 억제 방식

    중첩개수가 작은 후보부터 선택하되,
    이미 선택된 후보와 최소 5도 이상 차이 나는 경우만 추가

3) Pareto 후보 보존

    다음 기준 중 어느 하나에서도 다른 후보에 완전히 열세가 아닌 후보 보존:

    - 기존 개별 중첩개수
    - 중첩 ID 개수
    - 다른 집단 후보와의 방위각 이격 가능성
    - 중첩 면적

주의:

단순히 중첩개수가 작은 상위 20개만 남기면 222~241도처럼 좁은 구간의
연속 방위각만 남을 수 있다. 그러면 두 번째 집단에 배치할 70도 이상
떨어진 후보가 사라지므로 반드시 방위각 다양성을 보존해야 한다.


12. 현재 데이터에 권장하는 전체 처리 절차
------------------------------------------------------------

단계 1. 전체 후보 polygon 읽기

    자료/결과물/Polygon/12.5/1/Polygon_1.shp
    ...
    자료/결과물/Polygon/12.5/36/Polygon_36.shp

단계 2. 서로 다른 ID 후보 사이의 pairwise 중첩 테이블 생성

    id_1
    방위각_1
    id_2
    방위각_2
    중첩여부
    중첩면적(선택)

중첩 여부는 공간 인덱스로 후보 쌍을 줄인 후 실제 교차 면적이 0보다 큰지
확인해야 한다. 경계선 또는 꼭짓점만 닿는 경우는 중첩에서 제외한다.

단계 3. ID별 후보 축소

    - ID별 약 15~30개 후보 유지
    - 방위각 전 구간의 다양성 보존
    - 단순 상위 N개 방식만 사용하지 않음

단계 4. ID별 가능한 방위각 쌍 생성

    circular_difference(a,b) ≥ 최소 이격각

단계 5. GRASP 또는 탐욕+지역탐색으로 초기해 생성

    - 여러 무작위 ID 순서 사용
    - 각 반복에서 가장 좋은 후보 쌍과 집단 배치 계산
    - 한 ID 또는 두 ID의 후보를 교체하는 지역 탐색

단계 6. CP-SAT에 초기해 제공

    - 휴리스틱 해를 상한으로 사용
    - 실제 중첩 후보 쌍에 대해서만 보조변수 생성
    - 최대 실행 시간 설정

단계 7. 사전식 최적화

    - 최대 개별 중첩개수 최소화
    - 그 조건에서 전체 중첩 쌍 수 최소화

단계 8. 최종 결과 재검증

    - 각 ID가 제1집단에 정확히 하나 있는지 확인
    - 각 ID가 제2집단에 정확히 하나 있는지 확인
    - 같은 ID의 두 방위각이 최소 이격각 이상인지 확인
    - 집단별 polygon 중첩을 원본 geometry로 다시 계산
    - 최적화 행렬의 비용과 실제 공간 중첩 결과가 일치하는지 확인

단계 9. 결과 저장

13. 현재 안전지대_중첩.csv 사용 시 주의점
------------------------------------------------------------

현재 생성된 안전지대_중첩.csv의 중첩개수는 안전지대 폴더에 들어 있는
모든 선택 polygon을 동시에 배치했을 때의 값이다.

이 값을 단순 정렬하여 집단을 구성하면 전역 최소가 되지 않는다.
최종적으로 선택되지 않을 polygon과의 중첩까지 현재 점수에 포함되어 있기
때문이다.

전역 최적 배치에 필요한 핵심 정보는 polygon별 단일 중첩개수보다 다음과
같은 후보 쌍별 중첩 관계다.

    어떤 (ID, 방위각) polygon과
    어떤 (ID, 방위각) polygon이
    서로 면적으로 겹치는가?

따라서 최적화 전에 pairwise conflict matrix 또는 conflict edge table을
생성해야 한다.


14. 문제별 관련 개념 요약
------------------------------------------------------------

조건                                             관련 개념
------------------------------------------------------------
polygon 중첩을 그래프로 표현                     Geometric intersection graph
고정된 polygon을 두 집단으로 나눔                Max-Cut
두 집단의 크기도 같게 나눔                       Max-Bisection
각 ID에서 하나씩 선택하여 중첩 0                 Independent transversal
ID별 후보를 선택하면서 색칠                      Selective graph coloring
일부 중첩을 허용하면서 그 수를 최소화             Minimum-conflict/soft coloring
ID별 후보 하나를 고르며 쌍별 비용 최소화          Multiple-choice binary quadratic optimization
Boolean 선택변수 기반 정확 최적화                 CP-SAT, MILP
빠른 근사해                                      Greedy, GRASP, Tabu search, Simulated annealing
최악의 ID 중첩을 최소화                          Minimax optimization
최대 중첩 후 총중첩 순서로 최적화                 Lexicographic multi-objective optimization


15. 연구 또는 보고서에 사용할 수 있는 설명
------------------------------------------------------------

상세 표현:

    각 버티포트의 방위각별 접근·출발 polygon을 노드로 하고, 서로 다른
    버티포트 polygon 사이에 양의 면적 교차가 존재할 때 충돌 간선을 생성하여
    geometric conflict graph를 구축한다. 각 버티포트에서 최소 방위각 이격
    조건을 만족하는 두 후보를 선택하여 두 운용 집단에 각각 배치하고, 각
    집단에서 발생하는 충돌 간선 수를 최소화한다. 본 문제는 ID별 one-hot
    선택 제약과 집단별 쌍대 중첩 비용을 갖는 multiple-choice binary
    quadratic optimization 문제로 정식화할 수 있다.

간단한 표현:

    ID별 후보 선택이 결합된 두 집단 최소중첩 그래프 분할 문제.


16. 최종 권장안
------------------------------------------------------------

현재 자료에는 다음 조합이 가장 현실적이다.

    1) 전체 원본 후보에 대한 공간 중첩 그래프 생성
    2) 방위각 다양성을 보존하며 ID별 후보 축소
    3) 최소 이격각을 만족하는 ID별 방위각 쌍 생성
    4) GRASP 또는 탐욕+지역탐색으로 좋은 초기해 생성
    5) CP-SAT으로 해 개선 및 가능하면 최적성 증명
    6) 최대 개별 중첩을 먼저, 전체 중첩을 두 번째로 최소화
    7) 최종 선택 polygon을 실제 geometry로 다시 검증

Max-Cut, independent transversal, selective graph coloring이 각각 문제의
일부 구조를 설명한다. 하지만 방위각 후보 선택, 두 집단 배치, 최소 방위각
이격, 집단 내부 중첩 최소화를 모두 포함하는 전체 문제에는 ID별 one-hot
제약을 가진 이진 이차 최적화 모델이 가장 정확하다.
