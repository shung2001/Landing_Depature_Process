# 순환 용량 확장 실험

기존 분석의 안정 왕복 처리량과 링 자체의 순환 가능 대수를 분리했다. 아래 링 실험에서는 기체가 실제 SHP 선형을 따라 계속 이동하며 한 단계 안의 모든 기체 쌍 최소거리도 검사한다.

- 링 실험 352개, 전체 OD 실험 16개.
- 링별 진입 수요 120/360/720대/h를 1시간 동안 계속 생성한다. 링 자체 실험에는 착륙·출항이 없으므로 진입한 기체는 종료까지 순환한다.
- 단일 진입점과 출발지 비율을 반영한 여러 진입점을 비교한다. 다중 진입은 링 접속점에서 시작하며 접근선·Interchange 이동은 생략한다.
- 외곽 반시계/내곽 시계, 반경 50m 버퍼, 분리거리 100/250/500/1000m를 적용한다. 고정된 SHP/default 속도로 움직이며 진입 후 재배치나 정지는 하지 않는다.
- 기존 14대, 확대 28대, 기하학 상한으로 진입 한도를 비교한다. 공간이 부족하면 새 기체가 외부에서 기다린다.

## 전체 OD의 과부하와 추가 순환 비교

접근선→버티포트→출항의 기존 교차 예약 정책을 유지하며 수요 120/360대/h, 링 한도 14/28대, 두 시드, 방문 링마다 추가 0/2바퀴를 비교했다. 점유 대수와 실제 이동 중인 대수를 따로 기록한다. 추가 바퀴는 최단시간 경로에 의도적으로 더한 순환 대기 시험으로, 최단경로라고 부르지 않는다.

- 전체 OD에서 외곽 최대 점유 10대 / 최대 동시 이동 4대.
- 전체 OD에서 내곽 최대 점유 6대 / 최대 동시 이동 3대.
- Kepler OD 조건은 10대 이상 이동 지속시간, 동시 이동 최대 대수 합, 착륙+이륙 처리량 순으로 선정했다. 이는 시험한 조건의 비교 결과이며 전역 최적 운항 해는 아니다.

## Kepler CSV

- `kepler_ring_flow.csv`: 계속 생성한 링 순환 실험에서 선정한 시간별 점 궤적(5초 간격과 진입 시점).
- `kepler_OD_flow.csv`: 전체 OD에서 선정한 실제 이동·대기 궤적(10초 간격).
- `kepler_ring_paths.csv`: GeoJSON geometry 열로 외곽·내곽의 원본 경로를 표시한다.
- 좌표는 EPSG:5186에서 EPSG:4326으로 변환했다. longitude/latitude는 도, altitude_m는 원본 Z(m)다.
- timestamp는 UTC ISO 8601이며 2026-10-20 00:00:00 UTC를 시뮬레이션 0초로 정한 가상 시각이다. timestamp_ms도 함께 제공한다.
- Kepler에서 CSV를 추가하고 Point 레이어의 Lat/Lng를 latitude/longitude로 지정한다. 색상은 aircraft_id 또는 ring을 사용하고 timestamp에 시간 필터를 적용한다. 시간창을 약 5~15초로 좁혀 재생하면 현재 위치, 길게 잡으면 이동 흔적을 볼 수 있다.
- 점 CSV는 시간별 포인트 데이터다. 각 기체의 점을 다른 기체와 연결한 선으로 해석하지 않는다. 기체별 정렬 순서는 aircraft_id, time_s다.
