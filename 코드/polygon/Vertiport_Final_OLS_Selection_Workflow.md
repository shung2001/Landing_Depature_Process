# 후보 건물별 최종 OLS 선정 및 건물 간 진입표면 중첩 최소화

> **목표:** 후보 건물마다 최소 한 개의 대표 OLS를 배정하고, 가능하면 원형 최소각 **135° 이상**인 두 개를 배정한다. 건물 장애물에 대한 최상위 판정 조합을 유지하면서 **서로 다른 후보 건물의 선정 표면 간 XY 중첩 면적 합을 줄이는 방향을 공동 선정**한다.
>
> 코드: `코드/polygon/최종_OLS_선정.py`
>
> 출력: `자료/안전성/송파구/Separation_확보/최종_OLS`
>
> 범위: 연구용 표면의 중복 제거, 건물 침범 평가, 건물별 표면 배정, 건물 간 표면 중첩 최소화 및 결과 지도 생성. 실제 비행궤적·STAR·SID·항공교통 용량은 포함하지 않는다.

## 1. 후보 건물과 원본 ID

- OLS 배정 대상은 버티포트 후보 건물이며, 주변 장애물 건물 전체가 아니다.
- 현 자료에서는 `자료/결과물/Polygon/8/generation_summary.csv`의 `host_index`를 기존 소유관계로 사용한다.
- `building_id = HOST_<host_index>`로 그룹화한다. 원본 버티포트 ID 16개는 기존 매핑에 따라 후보 건물 8개로 연결된다.
- 같은 host의 중심점과 시작고도가 다르면 자동 병합하지 않고 입력 점검 오류로 처리한다.
- 원본 VP ID, Polygon ID, 원본 행 번호 및 대표 Polygon ID 관계는 모두 보존한다.
- 현재 footprint까지의 거리와 기존 요약표의 host 거리가 일치하지 않는 문제는 `OWNER_DISTANCE_CHANGED_CHECK_SOURCE_MAPPING`으로 기록한다. 현재 분석은 기존 매핑을 보존한 조건의 결과이며, 이 경고를 소유관계 확인 완료로 해석하지 않는다.

## 2. 입력 및 고정 설계

| 입력 | 현재 기본값 |
|---|---|
| 기존 OLS | `자료/결과물/Polygon/8/<id>/Polygon_<id>.shp` |
| 후보 목록·중심·시작고도 | 위 폴더의 `generation_summary.csv` |
| 장애물 건물 | `자료/안전성/송파구/송파구_건물_수정_update.shp` |
| DEM | `자료/안전성/송파구/송파구_DEM.tif` |
| 계산 좌표계 | EPSG:5186, 미터 |
| 길이 / 시작 폭 / 끝단 폭 | 1,000m / 0m / 573m |
| 경사 | **기존 8° 유지** |
| 방위각 | 진북 기준 시계방향, 기존 후보의 `rot_deg` |
| 높이 | 기존 Polygon Z의 DEM+AGL 기준 |

**8°와 8:1은 다르다.** 현재 자료는 8°로 생성되어 있으므로 경사를 임의로 8:1로 변경하지 않는다. 길이 1,000m에서 상승량은 `1000 × tan(8°)`이다.

건물 옥상은 footprint 내부 대표점에서 DEM 셀을 읽고 `roof_z = DEM + A16`으로 계산한다. A16은 AGL 높이로 사용하고, 결측·0·음수 또는 DEM 결측이면 UNKNOWN으로 남긴다. A17을 자동 대입하거나 출발 host를 임의로 제외하지 않는다.

Polygon과 건물은 동일 DEM 기준으로 비교한다. **DEM의 수직 datum을 독립 검증하지 않았으므로 높이를 검증된 AMSL로 단정하지 않는다.** 코드 필드명은 `z0_dem_agl_m`, `z_ref=DEM+AGL`로 표현한다.

## 3. 정확한 중복 제거

중복 제거를 장애물 평가 및 공동 선정에 앞서 수행한다.

1. 같은 소유 건물, 같은 중심, 같은 시작고도·경사·길이·폭·높이 산정 모델인지 확인한다.
2. Polygon Z를 `Shapely normalize`로 정규화한다. 링 시작점과 진행방향 차이는 제거하되 Z를 보존한다.
3. 위 조건과 정규화한 3D 형상이 완전히 같은 후보만 하나로 남긴다. 좌표를 반올림하지 않는다.
4. 1cm 이내 유사 형상은 `near_duplicate_flag`로 표시하고 자동 삭제하지 않는다.
5. 다른 소유자의 동일 표면은 소유관계를 보존한다. 계산은 캐시하고 지도에는 공유 형상을 한 번만 표시하는 전용 레이어를 제공한다.
6. 원본 후보 Shapefile 세트·요약표·실행 코드·이 문서는 `input_backup`의 ZIP에 보관한다.

기존 후보는 앞선 생성 단계에서 필터된 자료이다. **현재 선정은 이 후보 집합 안의 최적화**이며 0~359° 전체를 다시 검색한 결과가 아니다. 후보가 없는 건물만 같은 설계로 360방향을 재생성한다. 생성 자체가 불가능하면 `NO_GEOMETRY` 예외로 기록한다.

## 4. 각 후보의 건물 장애물 판정

1. XY 투영과 교차하는 모든 건물을 공간 인덱스로 조회한다.
2. 교차 영역 전체 꼭짓점에서 선형 표면고를 계산한다. 교차가 선이나 점인 경우도 평가한다.
3. `clearance = min(surface_z over overlap) - roof_z`를 계산한다.

| 조건 | status |
|---|---|
| 알려진 침범 존재: clearance < −0.000001m | FAIL |
| 침범 없고, UNKNOWN 중첩 또는 ±0.000001m 이내 접촉 존재 | REVIEW |
| 침범·접촉·UNKNOWN 중첩 모두 없음 | PASS |

접촉 공차는 수치 오차 처리용이며 요구 운항 분리거리가 아니다.

평가 필드: `penetration_count`, `worst_penetration_m`, `min_clearance_m`, `unknown_count`, `touching_buildings`, 관련 장애물 원본 행 목록.

유효한 중첩 건물이 없으면 최소 여유고는 NULL이다. PASS 후보 품질 비교에서는 제한 장애물이 없는 경우로 취급하지만 무한대 숫자를 여유고에 저장하지 않는다.

## 5. 건물별 허용 선택지와 유지 조건

공동 최적화 전에 각 건물의 모든 고유 후보 쌍을 검사한다.

```python
angle_diff = abs((a - b + 180) % 360 - 180)
paired_ok = angle_diff >= 135
```

건물별로 아래 **최상위 판정 조합 하나를 먼저 고정**한다.

1. PASS/PASS 쌍이 있으면 그 조합의 모든 135° 이상 쌍을 유지한다.
2. 없으면 PASS/REVIEW의 모든 해당 쌍을 유지한다.
3. 없으면 REVIEW/REVIEW의 모든 해당 쌍을 유지한다.
4. FAIL 포함 쌍은 허용하지 않는다.
5. 위 쌍이 없으면 단일 후보를 배정한다. PASS > REVIEW > FAIL 순서를 유지한다.
6. 단일 FAIL만 가능한 건물은 최악 침범량이 최소이고 그중 침범 건물 수도 최소인 집합으로 제한한 뒤 중첩을 비교한다.

**중첩 감소를 위해 PASS/PASS를 REVIEW/REVIEW로 바꾸거나, 두 개 가능한 건물의 표면을 한 개로 줄이지 않는다.** 최상위 조합 안에서 미확인 건물 수나 여유고는 중첩 최소화를 위해 달라질 수 있으므로 평가값을 그대로 공개한다.

각 쌍 안에서 1·2순위는 기존 단일 품질 순서로 부여한다. 두 표면의 조합을 먼저 고른 뒤 순위를 부여하며, 최고 단일 후보를 미리 고정하지 않는다.

## 6. 건물 간 진입표면 중첩 최소화

### 6.1 최적화 목적

서로 다른 건물에 속하는 **최종 선정 표면의 모든 쌍**에 대해 다음 값을 최소화한다.

```text
J = Σ area(XY(surface_i) ∩ XY(surface_j))
    i < j, building_i != building_j
```

- 단위는 m²이며 각 쌍은 한 번만 가산한다.
- 삼중 이상 중첩은 관련 표면 쌍마다 가산된다. 따라서 `overlap_sum_m2`는 중첩 영역을 한 번만 세는 union 면적과 다를 수 있다.
- 중첩 쌍 수와 중첩 영역 union 면적도 보조 지표로 기록한다.
- 면적 없는 경계 접촉은 목적함수에서 0이다. 면적 공차는 0.000001m²이다.
- 같은 건물의 두 표면은 135° 조건으로 관리하며 건물 간 중첩 목적함수에서는 제외한다.
- 높이가 떨어진 표면도 XY가 겹치면 면적을 가산한다. 높이차를 근거로 XY 중첩을 할인하지 않는다.

### 6.2 공동 탐색 방법

1. 모든 고유 후보 사이의 건물 간 XY 교차면적 행렬을 정확한 기하 연산으로 계산한다.
2. 기존의 건물별 독립 품질 선정 결과를 비교 기준선으로 보존한다.
3. 기준선 1개와 고정 난수 seed의 추가 초기 조합을 사용한다. 기본값은 **16개 시작점, 최대 60회 순회, seed 20261016**이다.
4. 한 건물을 제외한 나머지 선택을 고정한다. 그 건물의 **전체 허용 쌍 또는 단일 선택지**를 비교해 전체 J를 가장 작게 하는 조합으로 교체한다.
5. 같은 면적이면 미확인 수 → 접촉 수 → 최소 여유고 → 나머지 여유고 → 각도 차 → 작은 방위각의 기존 품질 순서로 결정한다.
6. 모든 건물을 순회하고 더 바뀌지 않을 때까지 반복한다. 여러 시작점의 결과 중 J가 가장 작은 결과를 채택한다.
7. 결정적인 마지막 순회를 수행하고, 수렴했다면 다른 건물 고정 시 어떤 한 건물의 허용 조합 전체 교체로도 J를 더 줄일 수 없는지 자동 검증한다.
8. **독립 선정 기준선보다 J가 증가하지 않았는지 검증**한다.

이 방법은 여러 건물을 함께 조정하는 다중 시작점 좌표 하강이다. 허용 조합을 임의로 상위 K개만 남기지 않는다. 다만 **전역 최소해를 보장하지는 않는다.** 실제 실행의 수렴 여부, 시작점 수, 반복 한도 및 면적 전후 수치를 저장한다.

### 6.3 중첩 영역의 높이 관계

최종 선정된 각 중첩 쌍에서 `delta_z = z_a - z_b`를 교차 영역 꼭짓점 전체에 계산한다. 두 표면은 선형이므로 그 최솟값·최댓값으로 높이 관계를 확인할 수 있다.

- 부호가 바뀌거나 0에 닿으면 실제 표면 교차/접촉으로 기록한다.
- 부호가 일정하면 최소 절대 높이차를 기록한다.
- `surfaces_cross_or_touch`, `min_vertical_gap_m`는 두께 없는 기하학적 표면의 진단값이다.
- 이번 실행에서는 높이차를 최적화 목적함수에 넣거나 운항 Separation 충족 여부로 판정하지 않는다.
- XY 중첩 면적 감소와 3D 교차 쌍 수 감소는 서로 다른 목표다. 면적이 줄어도 3D 교차 쌍 수는 늘 수 있으므로 전후 수치를 모두 보고한다.

## 7. 배정 결과의 의미

| selection_flag | 의미 |
|---|---|
| PASS_SELECTED | 건물 장애물 판정 PASS인 선정 후보 |
| CONDITIONAL_REVIEW | 미확인 높이·접촉 등 추가 확인이 필요한 후보 |
| UNSAFE_CANDIDATE | 알려진 침범이 있는 최선의 단일 대안 |

중첩이 줄어도 장애물 `status`는 바뀌지 않는다. 남은 중첩은 `REMAINING_INTER_BUILDING_XY_OVERLAP`로 검토 대상에 표시한다. 기하학적 표면 선정만으로 항공기 운용, 이착륙 분리, 공식 OLS 승인까지 확보됐다고 해석하지 않는다.

## 9. 검증 및 실행

- 모든 후보 건물은 1순위 1개를 가지며, NO_GEOMETRY 예외만 별도 기록한다.
- 건물당 표면 수는 1 또는 2, 두 개일 때 원형 최소각은 135° 이상이다.
- 건물별 최상위 판정 조합을 공동 최적화 전후 유지한다.
- 중복 제거 후에도 원본 16 VP 및 원본 Polygon 추적 관계를 보존한다.
- PASS/REVIEW/FAIL과 selection_flag를 혼동하지 않는다.
- 후보 장애물 판정을 다시 검사하고, 선정 표면의 공간 인덱스 조회를 전체 건물 교차 검사와 대조한다.
- 행렬 목적함수와 최종 중첩 영역 직접 계산 결과가 일치하는지 검사한다.
- 최종 J가 독립 기준선 이하인지 검증한다.
- 수렴 시 단일 건물의 허용 조합 변경으로 더 줄일 수 없는지 검증한다.
